# ADR 0002  Use Next.js + TypeScript for the frontend

**Status:** Superseded by ADR 0009

## Original Decision

Use Next.js with TypeScript for the product UI.

## Original Rationale

- structured routing
- strong TypeScript support
- dashboard-friendly
- good portfolio/deployment ergonomics

## Constraint

AI logic stays in the Python backend.

## Superseded

The implemented frontend evolved to React + Vite + TypeScript rather than Next.js.

See:

`0009-react-vite-typescript-frontend.md`
